# FilesMac releases

Downloads for **FilesMac**, a calm file manager and editor for macOS: browse like Finder, open any folder as a project, and edit right where you are.

**[Download the latest version](https://github.com/chethankumar/filesmac-releases/releases/latest/download/FilesMac.dmg)** · [All releases](https://github.com/chethankumar/filesmac-releases/releases)

- macOS 12 Monterey or later, Apple silicon and Intel (universal)
- Signed with a Developer ID and notarised by Apple
- Free for 7 days, then $5 once for a lifetime licence (up to 3 Macs, every update included)

To install, open the DMG and drag FilesMac to Applications. To update, do the same; your licence and settings stay put.

This repository only hosts release downloads. The app's source code is not public.
